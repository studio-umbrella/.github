# ☂ Studio Umbrella

Делаем продукты и инфраструктуру под брендом Umbrella: сервисы для учебного
процесса колледжа и общую платформу, на которой они живут.

## Образование

| Продукт | Что делает |
|---|---|
| [**Strike**](https://strike.umbrella.su) | Расписание и зарплата преподавателей. Публичное расписание по группе и преподу, подписка на календарь, Telegram-уведомления об изменениях. |
| [**Зачётка**](https://zachetka.umbrella.su) | Студенты, КТП, учебные материалы, тесты и ведомости преподавателя. |

## Платформа

| Продукт | Что делает |
|---|---|
| [**Umbrella ID**](https://id.umbrella.su) | Единый вход для продуктов Umbrella (OpenID Connect). |
| [**Umbrella Console**](https://console.umbrella.su) | Доступность, инциденты, релизы и бэкапы всех продуктов. |

## Как мы работаем

- Python + FastAPI на бэкенде, Vue 3 + Tailwind на фронтенде, PostgreSQL, Docker.
- Свой сервер: каждый продукт разворачивается сам по push в основную ветку —
  с бэкапом базы перед деплоем и автооткатом, если не прошёл healthcheck.
- Общий дизайн для всех продуктов и общий вход, к которому продукты подключаются по очереди.
