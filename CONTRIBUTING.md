# Соглашения Studio Umbrella

Общие для всех репозиториев организации.

## Коммиты

[Conventional Commits](https://www.conventionalcommits.org/ru/) на английском:

```
<type>(<scope>): <что сделано, в повелительном наклонении, с маленькой буквы>
```

| type | когда |
|---|---|
| `feat` | новая возможность для пользователя |
| `fix` | исправление ошибки |
| `refactor` | переделка без изменения поведения |
| `perf` | ускорение |
| `test` | только тесты |
| `docs` | только документация |
| `build` | сборка, зависимости, Dockerfile |
| `ci` | GitHub Actions, деплой |
| `chore` | прочее обслуживание |

- `scope` — часть репозитория: `server`, `web`, `bot`, `agent`, `api`, `auth`, `infra`
  или домен (`schedule`, `ktp`, `grades`).
- Заголовок до 72 символов, без точки в конце.
- Тело — по желанию: зачем, а не что; строки до 72 символов.
- Один коммит — одно логическое изменение. Рефакторинг, форматирование и новая
  возможность — разными коммитами.
- Без служебных trailer'ов и упоминаний инструментов, которыми писался код.

Примеры:

```
feat(schedule): copy a whole week with undo
fix(auth): restart login once when a stale callback comes back
ci(deploy): roll back on failed healthcheck
```

## Ветки

- Основная ветка — источник прода: push в неё разворачивает продукт.
- Работа — в ветках `feat/…`, `fix/…`, `docs/…`, `chore/…`, `ci/…`, слияние через PR.
- Слитые ветки удаляются.

## README

У каждого репозитория README начинается одинаково:

```markdown
# Название

Одно-два предложения: что это и для кого.

| | |
|---|---|
| **Зона** | Платформа / Образование / IT / Лаборатория |
| **Статус** | 🟢 В проде · 🟡 В разработке · ⚪ Прототип · ⚫ Выведен из эксплуатации |
| **Адрес** | ссылка на прод |
| **Стек** | основные технологии |
| **Вход** | Umbrella ID или свой |
| **Наблюдение** | как продукт подключён к Umbrella Console |
```

Дальше разделы в этом порядке: **Возможности**, **Структура**, **Локальный запуск**,
**Деплой**, затем специфичные для продукта.

## Подключение продукта к платформе

- **Вход** — через Umbrella ID (OIDC, Authorization Code + PKCE), см. README `umbrella-sso`.
- **Наблюдение** — по контракту Umbrella Console: `/health`, манифест
  `/.well-known/umbrella.json`, события релизов и бэкапов на `/api/v1/ingest`.
- **Интерфейс** — токены и каркас из `umbrella-ui`.
